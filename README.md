# Egyptian Currency Classification — CNN
A deep learning project that uses a Convolutional Neural Network (CNN) to automatically identify and classify Egyptian banknotes from images.

# Overview
This project addresses the problem of currency recognition using computer vision techniques. Given an image of an Egyptian banknote, the model predicts the denomination class it belongs to. The system was trained on a labeled dataset of Egyptian currency images and leverages CNN architecture to extract visual features and perform multi-class classification.

# Features

Image-based classification of Egyptian banknote denominations
CNN model trained from scratch for currency recognition
Preprocessing pipeline for image normalization and augmentation
Evaluation metrics including accuracy and loss curves

# Technologies Used

Python
TensorFlow / Keras (or PyTorch)
NumPy, Matplotlib
OpenCV / PIL for image preprocessing

# Model Architecture
The model is based on a Convolutional Neural Network with multiple convolutional and pooling layers, followed by fully connected layers for final classification. The architecture was designed and tuned to handle the visual characteristics of printed banknotes.
# Purpose
This project was developed to explore the application of CNNs in real-world image classification tasks, using Egyptian currency as a locally relevant and practical use case.
